# Keyboard shortcuts

::: tabs
== Mac
| | |
|---|---|
| New expense | <kbd>⌘E</kbd> |
| New income | <kbd>⌘I</kbd> |
| New transfer | <kbd>⌥⌘T</kbd> |
| New invoice | <kbd>⇧⌘I</kbd> |
| New bill | <kbd>⇧⌘B</kbd> |
| Search | <kbd>⌘K</kbd> |
| Back / Forward | <kbd>⌘[</kbd> / <kbd>⌘]</kbd> |
| New tab | <kbd>⌘T</kbd> |
| Close tab | <kbd>⌘W</kbd> |
| Next / previous tab | <kbd>⇧⌘]</kbd> / <kbd>⇧⌘[</kbd>, or <kbd>⌃Tab</kbd> / <kbd>⌃⇧Tab</kbd> |
| Go to tab 1–8, last tab | <kbd>⌘1</kbd>–<kbd>⌘8</kbd>, <kbd>⌘9</kbd> |
| New window | <kbd>⌘N</kbd> |
| Close window | <kbd>⇧⌘W</kbd> |
| New books | <kbd>⇧⌘N</kbd> |
| Open books | <kbd>⌘O</kbd> |
| Books settings | <kbd>⌥⌘,</kbd> |
| App settings | <kbd>⌘,</kbd> |
== Windows and Linux
| | |
|---|---|
| New expense | <kbd>Ctrl E</kbd> |
| New income | <kbd>Ctrl I</kbd> |
| New transfer | <kbd>Ctrl Alt T</kbd> |
| New invoice | <kbd>Ctrl Shift I</kbd> |
| New bill | <kbd>Ctrl Shift B</kbd> |
| Search | <kbd>Ctrl K</kbd> |
| Back / Forward | <kbd>Ctrl [</kbd> / <kbd>Ctrl ]</kbd> |
| New tab | <kbd>Ctrl T</kbd> |
| Close tab | <kbd>Ctrl W</kbd> |
| Next / previous tab | <kbd>Ctrl Shift ]</kbd> / <kbd>Ctrl Shift [</kbd>, or <kbd>Ctrl Tab</kbd> / <kbd>Ctrl Shift Tab</kbd> |
| Go to tab 1–8, last tab | <kbd>Ctrl 1</kbd>–<kbd>Ctrl 8</kbd>, <kbd>Ctrl 9</kbd> |
| New window | <kbd>Ctrl N</kbd> |
| Close window | <kbd>Ctrl Shift W</kbd> |
| New books | <kbd>Ctrl Shift N</kbd> |
| Open books | <kbd>Ctrl O</kbd> |
| Books settings | <kbd>Ctrl Alt ,</kbd> |
| App settings | <kbd>Ctrl ,</kbd> |
:::

With the mouse: <kbd>⌘</kbd>-click (<kbd>Ctrl</kbd>-click) or middle-click a link to open it in a new tab. See [Tabs, windows and search](./tabs-and-search).
